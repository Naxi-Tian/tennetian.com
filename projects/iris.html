IRIS eye-tracking wearable

A wearable system that tracks the user’s gaze and generates concise, real-time spoken narration of what they are looking at.

RoleSoftware engineer
ContextENIAC XI Hackathon
Team3 members
Eye gaze→Image region→LLM prompt→Spoken narration

The goal

Describe the part of the world a user chooses to notice.

IRIS was designed for low-vision assistance. Instead of narrating an entire scene indiscriminately, the concept uses eye gaze to indicate which visual region matters in that moment.

My contribution

Designing the gaze-to-language pipeline.

  • Translated raw gaze and image input into a focused prompt for the language model.
  • Shaped model output for concise, real-time spoken narration.
  • Owned product scoping and feature prioritization within the three-person team.
  • Balanced useful scene description against response length and speed.

System logic

Focus first, then describe.

The core design choice was to treat gaze as intent. That reduced the scope of what the model needed to interpret and created a more direct relationship between where the user looked and what the device said.
